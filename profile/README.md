# LogLens — the AI Monitoring Tool

Local-first, zero-touch anomaly detection for logs (and soon metrics and traces).
Measured against public benchmarks — including where we lose. Scripts are public.

- **LogLens-AI** — the free, open-source analyzer and CLI (Python).
- **loglens-bench** — the public scoreboard anyone can rerun.
- **lensd** — the premium Go engine (one binary: one node → vertical → cluster).
- **lens-dashboard** — the premium UI.
- **loglens-web** — website, waitlist, Apex Preview sign-up.

> We never say "SOTA", "most accurate", or "best". We say "measured X on benchmark Y; scripts are public."
